IMPLEMENTED
1. Engineering modules: nine choices across Dyson Swarm, Neutron Forge and
   Reality Loom, plus Standard. Unlock stages 1/2/4, one active module per
   project, one-hour switching cooldown. Benefits have production, transport,
   input or construction tradeoffs. Switching preserves accumulated work.
   Choices survive resets; effects wait for their unlock stage to return.
2. Goal automation: up to six ordered construction/stock goals. Hold automatic
   resets until completion; then Save, Resume, Energy, Matter or Time. Save stops
   automatic spending and resets and protects current Home stock. Goals and
   current position are part of complete operations profiles. Manual resets
   remain available. Locked construction goals explain Ascension/Endless horizon.
3. Six-hour laboratory: current configuration versus an Energy/Matter/Time plan
   or saved Home operations profile. Separate serialized copies, literal 60 Hz
   replay, construction work, stock, spending by resource, resets and sampled
   blocking reasons. Live economy keeps running. A separate worker publishes immutable progress snapshots; 30-second runs,
   cancellation and explicit continuation. Worker copies never write saves.
4. Challenges: three additional rule families distributed over the existing
   twelve challenges: 25 units per process; no resonance/expeditions; double
   input consumption. Existing resource handicaps/rewards remain. Isolated
   six-hour readiness trials use guided purchases and report measured outcomes,
   actual targets and diagnostics. Cancelled real attempts record their result.
5. Expedition discovery: eight persistent anomaly signals; once revealed, pick
   Survey (15% shorter, 15% lower reward) or Recovery (20% longer, 20% higher
   reward). Permanent route choice applies to future launches, including offline
   automation. Existing voyages retain their launch terms. Signals never expire.
6. Parallel roles: Balanced, Energy supplier, Refinery and Construction support.
   Production/input/export tradeoffs; actual Energy deliveries to Home activate
   a temporary 2% construction bonus per support world, maximum 4%. Imported
   stock does not become lifetime production. Roles persist; major resets clear
   active delivery support and retain the existing transfer reactivation rule.
7. Repeatable practice: reserves, input bottlenecks and Prestige resets. Each
   lesson runs the real engine on a separate economy, available on existing saves
   and before progression. Only completion/history flags reach the campaign.
8. Finale and chronicle: completion time, projects, modules, routes, roles,
   focus, historical resets and a bounded decision history. Three optional
   post-campaign scenarios use separate save and checkpoint slots. Start/resume,
   return to campaign, deterministic seed/goal and completion records. Corrupt
   scenario slots are preserved; imports cannot cross campaign/scenario slots.

COMPATIBILITY AND NUMERICS
New choices default to inactive/Standard/Balanced in existing saves. Existing
points, unlocks and purchased research are preserved. No user save is migrated
on disk by this development work. Preserve original Unity metadata.
The tests exposed minimum-quantum reserve depletion and floating-point dust
in a parallel economy. Sub-quantum input allocation now respects available
stock; protected stock is clamped at depletion; stock below one minimum incoming
flow quantum is treated as supply-limited. Both live and offline use this logic.
A fixed reproduction fixture lives in Tools/Expansion/Fixtures/depletion.json.

BUG FIXES FOUND DURING VALIDATION
- Sub-quantum resource depletion and parallel floating-point dust could stall
  progress at a numerical boundary. Fixed input allocation, protected stock,
  accounting and the stored-stock threshold; the saved reproduction and full
  campaign runs now advance normally.
- Running both laboratory copies on the UI thread was too slow. A cancellable
  background worker now publishes immutable snapshots, with pause/continuation.
- Discovery actions initially pushed the late-game progress card below the
  visible overview. They now follow the campaign card.
- The transfer interval tooltip now describes its actual -20% interval, and
  the laboratory reports all unlocked stocks and current stock-goal progress.

-o Tools/Expansion/bin/Final, then execute that exact Expansion.dll with the
repository path and optionally --system-audit or --discovery-audit. The explicit
DLL path avoids dotnet run resolving a stale default output during custom-path
builds. Core evidence here is from direct execution of the current compiled DLL.

--tag=discovery --verify-target --hours=480. Run Unity jobs sequentially via
