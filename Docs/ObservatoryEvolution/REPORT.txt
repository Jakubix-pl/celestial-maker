CELESTIAL MAKER 2.5.0 - OBSERVATORY EVOLUTION
2026-10-11

IMPLEMENTED - eight approved features
1. Diagnostics identify protected inputs, insufficient supply, paused processes,
   inactive autobuy and research needs; actions open the relevant economy/view.
2. Return briefing lists actual offline discoveries and retained goals. Persistent
   contextual guides explain current views and discovered systems.
3. Complete operations profiles save queues, reserves, order, routing, construction
   and reset rules per economy. Restore after reset is explicit; locked rules wait.
4. Reset forecasts run the real Simulation on a serialized copy, with retained or
   restored rules. They sample each simulated minute up to 48h and stop after a
   four-second calculation budget. Unknown recovery is reported honestly. Up to
   24 historical runs record actual recovery before the next reset interrupts it.
5. Interactive flows show discovered producers, current gross/net/consumption,
   protected stock and consumers; links trace inputs or open process details.
6. Energy, Matter and Time focus affect construction and transport with tradeoffs.
   They require matching branches and have a ten-minute switch cooldown. Losing
   the prerequisite suspends the effect until it is earned again. Existing transfer
   dates are never accelerated by switching. Imports do not award lifetime output.
7. Native vector cosmos geometry follows chapters, megastructures and universes.
   Partial construction and earned Orbital/Stellar/Genesis styles use actual state.
8. Twelve local restore points retain prior progress before imports, New Game and
   resets. Prestige snapshots are limited to one per ten simulated minutes.
   Restoration saves the current state first and does not re-award real elapsed time.
   Invalid points remain visible and cannot be loaded. User saves were not used
   as mutation targets. Optional fields preserve the existing schema/version.
